# Expense Tracker Web Application

A simple web-based Expense Tracker built using Python Flask and SQLite.

## Features

- User registration
- User login and logout
- Session-based authentication
- Add expenses
- View personal expenses
- Delete expenses
- SQLite database
- Simple and responsive user interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2
